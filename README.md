# 🔍 User Search App

A dynamic user search application built with JavaScript that fetches data from an external API and filters users in real time.

---

## ✨ Features

- Fetch user data from an API
- Real-time search functionality
- Dynamic rendering with JavaScript
- Responsive user cards
- Empty state handling
- Clean and modern UI

---

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- Fetch API

---

## 📦 API Used

```bash
https://jsonplaceholder.typicode.com/users
```

- Handling asynchronous JavaScript
